# trihologic.by – прототипы главной

Четыре варианта главной страницы интернет-магазина трихологической косметики TRIHOLOGIC (Минск). Клиент Pirus Agency.

- `index.html` – обложка с живыми превью
- `v1.html` – вариант 1 «Кабинет»: светлый, ближе всего к текущему сайту
- `v2.html` – вариант 2 «Назначение»: редакционный, подбор ухода за три шага
- `wow.html` – WOW «Корень»: тёмный, волосы на canvas растут и тянутся к курсору
- `wow2.html` – WOW 2 «Капля»: светлый, аква-жидкость на WebGL в первом экране

Весь контент снят с живого сайта 06.10.2026 и лежит в `src/data.js` (один источник для всех вариантов). Страницы собираются из шаблонов `src/tpl-*.js`:

    node build.js

Картинки подключены ссылками с trihologic.by. Бриф и решения – `docs/brief.md`.

## Проверка
